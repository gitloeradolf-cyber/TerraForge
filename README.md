# TerraForge

**TerraForge** — это кастомный лаунчер для Minecraft, написанный на **Rust** с использованием **egui/eframe**. Он создан для работы с клиентом **Horizon** (Minecraft: Rust Edition) и предлагает уникальный оранжевый интерфейс, автопоиск игры и быстрый запуск.

## ✨ Особенности

- **Автопоиск Minecraft:** Лаунчер сам находит папку `.minecraft` и проверяет наличие версии `26.3`.
- **Оранжевый интерфейс:** Минималистичный дизайн в цветах логотипа TerraForge.
- **Прямое подключение:** Вкладка «Сервера» позволяет подключаться к Java-серверам по IP.
- **Профиль игрока:** Смена ника, пароля и выбор скина (в разработке).
- **Установщик:** В комплекте идёт установщик, который скачивает лаунчер с GitHub и создаёт ярлык на рабочем столе.

## 🛠️ Технологии

- **Rust** — основной язык.
- **eframe / egui** — графический интерфейс.
- **Horizon (Rust Edition)** — движок самого клиента Minecraft.
- **GitHub Releases** — для распространения обновлений.

## 🚀 Как запустить

1. Скачай последний релиз из раздела **Releases**.
2. Запусти `terraforge.exe` (или установщик `installer.exe`).
3. Введи никнейм и нажми «Играть».
